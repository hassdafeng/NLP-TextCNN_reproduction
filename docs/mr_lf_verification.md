# TextCNN MR 数据修正与实验核验

## 数据修正

中期代码先将文件解码为字符串，再调用 `.splitlines()`。部分评论包含 `0x85`，解码后成为 NEL 字符，旧方法会在它的位置断开一条评论。正例文件有 13 处，负例文件有 10 处，所以中期统计为 10,685 条。按物理行读取得到正负各 5,331 条，共 10,662 条，与原始语料说明一致。 [MR 句子情感数据 v1.0](https://www.cs.cornell.edu/people/pabo/movie-review-data/rt-polaritydata.README.1.0.txt)

修正后的数据仍使用种子 2026 生成固定分层划分。逐条核查确认每个 ID 只出现一次，且文本和标签均能追溯到原始文件的对应行。 [数据清单](../data/processed_lf/manifest.json)

| 划分 | 负例 | 正例 | 合计 |
| --- | ---: | ---: | ---: |
| 训练 | 4,265 | 4,264 | 8,529 |
| 验证 | 533 | 533 | 1,066 |
| 测试 | 533 | 534 | 1,067 |

中期数据和历史结果见 [`data/processed/`](../data/processed/) 和 [`results/`](../results/)。修正后的样本 ID 以文件物理行为准，测试集组成发生变化。两版得分仅作历史对照，不能把分差归因于切分修复本身。

## 修正后结果

| 设置 | 窗口 | Accuracy 均值〔范围〕 | Macro-F1 均值〔范围〕 |
| --- | --- | ---: | ---: |
| CNN-rand | `[3,4,5]` | 71.26%〔70.10–72.35%〕 | 70.84%〔69.76–72.30%〕 |
| CNN-static，冻结 SVD 向量 | `[3,4,5]` | 70.73%〔69.92–71.51%〕 | 70.29%〔69.01–71.09%〕 |
| CNN-non-static，训练 SVD 向量 | `[3,4,5]` | 75.45%〔74.23–76.10%〕 | 75.31%〔74.15–75.99%〕 |

相同窗口下，SVD 向量随训练更新的设置在三个种子中都高于冻结设置。窗口从 `[3,4,5]` 改为 `[2,4,5]` 后，平均 Accuracy 增加 0.78 个百分点，平均 Macro-F1 增加 0.89 个百分点。种子 13 的两项指标均下降，平均增益来自另两个种子。 [逐次汇总](../results/mr_lf/all_runs.csv) · [独立复算](../results/mr_lf/verification.json)

案例表按改对与改错、正例与负例各抽 3 条，跨种子按样本 ID 去重。以下两例同属种子 13，概率为模型给正类的概率。 [12 条案例](../results/mr_lf/cases.csv)

- `mr-neg-00038` 从误报正类改为正确负类，概率从 0.7946 降到 0.2685。片段有“fun -- but bad”的转折，既说电影有趣，也明确说它不好。调整后的预测更符合标签。
- `mr-pos-00169` 从正确正类变为误判负类，概率从 0.7684 降到 0.4994。“effective and claustrophobic thriller”是在肯定惊悚效果，理解“claustrophobic”依赖所在语境。调整后的概率刚越过分类边界。

这些案例展示了窗口调整带来的不同方向的预测变化。具体词语或短语是否造成翻转，还需额外分析模型输出。

## 复跑与核验入口

四种设置各跑种子 13、42、2026，每次训练五轮。词表和 SVD 向量从训练集建立，各轮在验证集评估，选择验证集 Macro-F1 最好的模型，在测试集上评估。两组窗口消融共用划分、种子和其他超参数，把窗口 `[3,4,5]` 改为 `[2,4,5]`。

环境为 Windows x64、Python 3.12.14、PyTorch 2.5.1+cpu、scikit-learn 1.6.1、NumPy 2.2.6、pandas 2.2.3。12 次训练与评估的记录耗时合计约 293 秒。运行和独立核验命令见 README，完整依赖见环境清单。 [运行命令](../README.md#快速开始) · [环境清单](../results/mr_lf/environment.txt)

核验脚本可用 Python 标准库直接运行。它会查验数据摘要、样本覆盖、标签、日志和配对设置，从保存的逐条预测重算 Accuracy、Macro-F1 和窗口调整的修正与退步数。 [核验脚本](../code/verify_mr_lf.py)

本次对照使用训练集 50 维 SVD 词向量和固定留出划分，复现的是本组的缩规模设置。Kim 原文在 MR 上的 300 维预训练词向量和交叉验证结果应另行呈现。 [Kim 2014](https://aclanthology.org/D14-1181/)

Codex 辅助了行切分修复、实验执行、指标复算和这份说明的整理。组内贡献记录应按成员实际承担和核验的工作填写。
